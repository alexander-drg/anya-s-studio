# Anya's Studio

Create a premium, artistic portfolio website for a female visual artist and creative practitioner.
This is NOT an e-commerce website. Do not include a cart, prices, product cards, "Buy Now" buttons, or anything that makes the work feel like an online shop.
The website should feel like entering the artist's personal world: calm, intimate, tactile, thoughtful and slightly poetic.
Core concept
The website revolves around four values:
Presence — learning to truly be present, whether looking at a painting, participating in a session, or drawing.
Curiosity — not intellectual curiosity, but the childlike sense of wonder that allows us to continue discovering.
Beauty — not decorative beauty, but beauty that comes from authenticity.
Balance — not perfection, but a living balance between body, mind, emotions and creative expression.
The website should communicate:
presence
authenticity
curiosity
inner exploration
creativity
natural beauty
balance
sensitivity
personal growth
artistic process
It should feel more like an invitation to slow down and discover than a website trying to sell something.
Visual references
Use these websites as high-level inspiration:
helenbooth.com
anamariapanaitescu.com
Do NOT copy either website.
Take inspiration from their use of:
large artwork
generous negative space
minimal navigation
editorial layouts
sophisticated typography
image-led storytelling
restrained text
quiet, gallery-like presentation
The result should have its own identity.
Visual direction
Use a warm off-white / cream background instead of sterile pure white.
Suggested palette:
warm ivory / cream
soft beige
muted stone
charcoal
muted sage or petrol/teal as a very subtle accent
optional warm earthy brown / terracotta in small details
Avoid bright saturated colors.
Use an elegant editorial serif typeface for large titles combined with a clean, understated sans-serif for navigation, metadata and smaller text.
Typography should feel like an art book or independent editorial publication, not a startup landing page.
Use very large typography selectively.
Create a lot of breathing room between sections.
Avoid excessive cards, boxes, shadows, gradients and rounded SaaS-style UI components.
The layout can occasionally be asymmetric and slightly unexpected, while still remaining elegant and balanced.
Organic details
Introduce very subtle handmade elements inspired by the artist's process:
small handwritten words
hand-drawn lines
imperfect circles
pencil marks
scanned paper textures
close-up details of paintings
fragments of a sketchbook
These should be subtle accents rather than decorative gimmicks.
The site should still feel sophisticated.
Homepage
Create a homepage with the following structure.
1. Minimal header
Artist name/logo on the left.
Navigation:
Work
About
Fractal Drawing
Sessions
Journal
Contact
Keep navigation extremely clean.
Optionally include RO / EN language switching.
2. Hero
Do NOT create a conventional marketing hero with a giant button.
Use one powerful full-height or near-full-height artwork/studio image.
Include a short poetic statement such as:
"Art as a way of being present."
or
"A space for art, presence and discovery."
Keep the text short.
The artwork should remain the main focus.
3. Intro / manifesto
A very short introduction explaining that her practice explores the relationship between creativity, presence, curiosity and inner balance.
Use a large editorial text treatment with generous whitespace.
4. Selected work
Show selected artworks using a gallery/editorial composition rather than identical cards.
Mix:
large landscape images
portrait images
close-up details
occasional full-width artwork
Hover can reveal:
Title
Year
Medium
Keep interaction subtle.
5. The four values
Create an elegant section presenting:
Prezență
Curiozitate
Frumusețe
Echilibru
Do NOT design this like four corporate feature cards.
Instead make it feel editorial and artistic.
Each value should contain one very short explanation and perhaps a tiny organic hand-drawn symbol.
6. Artist / process
Combine a portrait or studio photograph with a short personal introduction.
Show that the artist is interested not only in completed objects but also in the process of creating and discovering.
Include photographs such as:
hands working
paint
paper
sketchbooks
studio details
unfinished work
materials
7. Fractal drawing
Introduce fractal drawing as part of her creative practice.
This should feel connected to exploration, presence and self-discovery rather than presented like a commercial service.
Include a link to a dedicated Fractal Drawing page.
8. Sessions
Create a subtle section explaining creative / artistic sessions if applicable.
The tone should be personal and inviting rather than promotional.
Use something like:
"An invitation to explore through making."
rather than aggressive calls to action.
9. Closing statement
Finish with a quiet full-width section containing one short sentence or quote related to authenticity, creativity or presence.
Then a very minimal footer containing:
Instagram
Email
Location if relevant
Copyright
Work page
Create an editorial artwork archive.
Allow categories if needed, but avoid a heavy filtering interface.
Each project/artwork page should include:
title
year
medium/material
dimensions if available
short optional description
large images
close-up details
next/previous work navigation
Artwork should always dominate the screen.
About page
The About page should feel personal rather than like a CV.
Structure it around:
her story
artistic philosophy
her relationship with creativity
the four values
selected exhibitions / education / experience later on
Use portraits and studio/process photography.
Fractal Drawing page
Explain:
what fractal drawing means in her practice
why she uses it
the relationship with presence, curiosity and exploration
examples of drawings
photographs of the process
Make this visually more experimental than the standard portfolio pages.
Sessions page
If she offers individual or group creative sessions, create a simple informational page.
Do not make it look like a booking SaaS application.
Explain the experience first.
A contact/enquiry CTA at the bottom is enough.
Interaction and animation
Animations should be slow, subtle and elegant.
Use:
soft image reveals while scrolling
very subtle parallax where appropriate
fade/translate text entrances
elegant hover transitions
image zoom of approximately 2–4% on hover
smooth page transitions if technically reasonable
Do NOT overanimate the site.
Avoid flashy cursor effects and gimmicks.
The feeling should remain calm.
Responsive design
The site must be fully responsive.
On mobile:
maintain large imagery
preserve generous whitespace
use a minimal hamburger navigation
avoid shrinking everything into tiny cards
retain the editorial/art-book feeling
Content
For now use tasteful placeholder artwork and placeholder photography.
Do not invent an artist biography or credentials.
Use [ARTIST NAME] where the real name is unknown.
Use short placeholder copy that can easily be replaced later.
Default copy can be Romanian, but structure the website so that Romanian and English can eventually be supported.
Overall feeling
Think:
contemporary art gallery
+
artist's sketchbook
+
quiet editorial magazine
+
personal creative journal
Not:
corporate website
startup
wellness influencer
online store
generic therapist website
generic Squarespace artist template
The final experience should be minimalist but not cold, artistic but not confusing, feminine without becoming stereotypically feminine, and sophisticated without feeling pretentious.
Above all, the artwork and the artist's worldview should be the focus.
